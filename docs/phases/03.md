## NV-03-01

**Outcome / scope:** Implement scoped HTTPX sessions, source-family budgets, timeouts and bounded streaming.

**Requirements:** NET-01 QA-01. **Dependencies:** Phase prerequisites above and the approved baseline.

### Acceptance

- **NV-03-01-AC1:** Per-family pooled sessions enforce configured concurrency, request/byte/deadline budgets and bounded queues under sustained work.
- **NV-03-01-AC2:** HTTP/2 negotiation failure falls back appropriately; response streaming cannot exceed limits and client cleanup releases resources.
- **NV-03-01-AC3:** Record observed acceptance evidence under [the common evidence rule](../WORKFLOW.md#definition-of-done) for the criteria and verification design below.

### Verification design

Use fake clock/transport with concurrent tasks, large streams and timeout boundaries. Measure peak in-flight work and verify no leaked connections after cancellation.

**Requirements:** NET-01 QA-01. **Dependencies:** `NV-03-01` plus applicable prerequisite contracts. Independent work may continue only under the phase dependency rule above.

### Acceptance

- **NV-03-02-AC1:** 429/403/5xx/timeouts follow the declared retry/circuit policy and total deadline; session refresh is serialized rather than multiplied by waiting tasks.

## NV-03-04

**Outcome / scope:** Implement bounded shared filing detection/decoding, offline taxonomy resolution and pure source assertions for evidenced XML/inline-XBRL/legacy-financial-HTML families; independent semantic mapping remains in phases 13/14.

**Requirements:** NET-02 QA-01. **Dependencies:** `NV-03-03` plus phase prerequisites; use sequential internal checkpoints as needed; no separate execution-plan files.

### Acceptance

- **NV-03-04-AC1:** Content-based dispatch and source-assertion decoding preserve namespaced concepts, original values, periods, units, dimensions and locators for each evidenced XML/inline-XBRL/legacy-financial-HTML family. URL/year/context-name guesses cannot select facts.
- **NV-03-04-AC2:** Closed local taxonomy resolution, disabled external resource access and finite size/depth/fact/time/memory limits reject malformed, unsupported and challenge inputs with typed failures; cancellation releases owned resources.
- **NV-03-04-AC3:** Record observed acceptance evidence under [the common evidence rule](../WORKFLOW.md#definition-of-done) for the criteria and verification design below.

### Verification design

Pair independently checked real-family samples with prefix/context permutations, inline sign/scale/continuation cases, HTML spans/captions and adversarial entities/references. Assert exact source assertions, no network/file escape, bounded work and honest missing-taxonomy/unsupported-family status. Lock/test the selected optional processor on CPython 3.14; verify core import without it.
