<a id="nv-08-01"></a>
## NV-08-01

**Outcome / scope:** Index catalog/variant identity and historical-price adapter.

**Requirements:** IDX-01 TIME-01. **Dependencies:** Phase prerequisites above and the approved baseline.

### Acceptance

- **NV-08-01-AC1:** Index identity distinguishes price variants and source aliases; historical price dates and missing periods preserve their actual coverage.
- **NV-08-01-AC2:** An ETF or current index value cannot satisfy the requested historical index series.
- **NV-08-01-AC3:** Record observed acceptance evidence under [the common evidence rule](../WORKFLOW.md#definition-of-done) for the criteria and verification design below.

### Verification design

Use separate price/variant fixtures, alias collisions, empty history and date boundaries. Assert typed identity plus exact daily values and source lineage.

<a id="nv-08-02"></a>
## NV-08-02

**Outcome / scope:** Valuation and TRI adapters with separate schemas and coverage.

**Requirements:** IDX-01. **Dependencies:** `NV-08-01` plus applicable prerequisite contracts. Independent work may continue only under the phase dependency rule above.

### Acceptance

- **NV-08-02-AC1:** Valuation PE/PB/yield and TRI use separate declared schemas/identities; null and genuine zero values remain distinct.
- **NV-08-02-AC2:** Joining datasets cannot relabel TRI as price or introduce unsupported valuation dates.
- **NV-08-02-AC3:** Record observed acceptance evidence under [the common evidence rule](../WORKFLOW.md#definition-of-done) for the criteria and verification design below.

### Verification design

Test disjoint/overlapping date ranges, nullable values and incompatible variant requests against manually expected joins and schema errors.

<a id="nv-08-03"></a>
## NV-08-03

**Outcome / scope:** Verify historical volatility-index access if available; test null/zero valuations and variant mistakes.

**Requirements:** IDX-01 TIME-01. **Dependencies:** `NV-08-02` plus applicable prerequisite contracts. Independent work may continue only under the phase dependency rule above.

### Acceptance

- **NV-08-03-AC1:** Historical volatility-index capability is supported only for a verified source/interval; a current VIX response produces a capability limitation.
- **NV-08-03-AC2:** Wrong variant and invalid valuation assumptions are detected without inventing substitute history.
- **NV-08-03-AC3:** Record observed acceptance evidence under [the common evidence rule](../WORKFLOW.md#definition-of-done) for the criteria and verification design below.

### Verification design

Combine bounded timestamped capability evidence with offline current-only and mistaken-variant cases. Preserve explicit blocked status where historical access is unavailable.
