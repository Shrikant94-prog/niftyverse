# Phase 22 — Hardening, documentation and release candidate

<a id="entry"></a>
## Entry and goal

**Goal:** Measured release readiness, artifacts, and explicit data limits.

**Prerequisite gates:** all earlier software phases (00–21), with explicit unresolved source limitations retained. Verify relevant evidence; a phase number alone is not proof. Only an explicit dependency exception below permits independent work before an entire prerequisite phase closes.

**Scope boundary:** Complete this phase only. Future phase features remain excluded; no wholesale repository redesign or new provider scope.

**Read selectively:** [phase loop](../WORKFLOW.md#phase-loop) once, then these topic sections only when required by the active checkpoint: [§16.](../specs/verification.md#s16), [§19.](../specs/verification.md#s19), [§20.2](../specs/verification.md#s20-2), [§16.7](../specs/verification.md#s16-7).

**Acceptance references:** R2, AM-02, AM-05, AM-07, AM-08, AM-09, AM-10, AM-12, AM-13, AM-14, AM-15, AM-16, AM-17. Look up only the assigned rows in [the amendment register](../specs/requirements.md#s18-2).

**Sequential checkpoints:** [NV-22-01](#nv-22-01) → [NV-22-02](#nv-22-02) → [NV-22-03](#nv-22-03) → [NV-22-04](#nv-22-04). Complete ordinary testing and repairs inside this goal; no owner prompt after each checkpoint. The authoritative expected outcomes are below. Current progress belongs only in root STATE.

At checkpoint entry, inspect affected interfaces/code/tests and bind independent expected cases to the listed acceptance. Before closure, run focused checks plus the integrated gate and affected regressions. See [evidence and completion](../WORKFLOW.md#definition-of-done); AC3 never means test count alone.

## Release gate and limitations

A mandatory unsupported capability keeps the unrestricted release claim blocked unless the owner explicitly accepts a restricted release scope. Record limitations precisely; a readiness report may be complete while a full-release gate remains blocked. Human review of a limitation does not automatically waive it. Package publication is separate from producing a verified release candidate.

## Phase integration gate — PH-22-GATE

every requirement has passed evidence or an explicit owner-reviewed blocking limitation. A partial historical dataset cannot be advertised as complete. No implementation of deferred features to compensate for unfinished current scope.

## NV-22-01

**Outcome / scope:** Run complete fault/recovery/platform/dependency matrix and measured local performance workload; fix actual bottlenecks. Include filing-extra isolation/security/resource tests, output-mode parity/atomicity, ETF and aggregate-bar regressions.

**Requirements:** QA-01. **Dependencies:** Phase prerequisites above and the approved baseline.

### Acceptance

- **NV-22-01-AC1:** All declared Python 3.14 platform/core/extra lanes and critical fault/recovery scenarios have current evidence; failures remain visible.
- **NV-22-01-AC2:** Performance results record hardware, versions, workload, cache state, memory/spill/disk and repeated measurements; claimed budgets are measured.
- **NV-22-01-AC3:** Record observed acceptance evidence under [the common evidence rule](../WORKFLOW.md#definition-of-done) for the criteria and verification design below.

- **NV-22-01-AC4:** The relevant runtime matrix exercises optional filing isolation/resource limits, DB/direct-output parity/atomicity, ETF and EOD aggregation behavior (AM-14–AM-17).

### Verification design

Run the full existing suite, process recovery matrix and representative benchmarks from PLAN [§16.6](../specs/verification.md#s16-6), including both export query shapes and total-process/spill/restore headroom. Investigate material regressions against recorded baselines; do not gate noisy shared CI on a single timing sample or invent speed multipliers.

- **NV-22-04-AC1:** Wheel and sdist install cleanly with declared extras and type metadata; package contents exclude secrets, datasets, local stores and unrelated artifacts.
