## NV-20-01

**Outcome / scope:** Complete command surface/help/config diagnostics and explicit maintenance previews. Include explicit extract, local filing parse, instrument search and fact trace commands, with store versus direct-output semantics.

**Requirements:** UX-01 DOC-01. **Dependencies:** Phase prerequisites above and the approved baseline.

### Acceptance

- **NV-20-01-AC1:** Every command documented in PLAN §14 parses and dispatches to the shared API with correct help, validation and exit status.
- **NV-20-01-AC2:** Initialization handles destination conflicts and maintenance commands preview their scope before destructive operations under explicit authorization.
- **NV-20-01-AC3:** Record observed acceptance evidence under [the common evidence rule](../WORKFLOW.md#definition-of-done) for the criteria and verification design below.

- **NV-20-01-AC4:** Extract, local filing parse, search and trace commands match API contracts, distinguish direct output from snapshot export and produce scoped optional-extra/error hints (AM-17).

### Verification design

Run installed CLI commands with temporary files/stores, invalid configs and existing destinations; assert no unexpected writes/downloads from help/init/doctor defaults.
