## Finding and repair

The final review found one blocking defect: CSV data was hashed, then reopened,
allowing a changed file to be parsed without the verified checksum. A new
regression failed before the repair, returning `9.0000` instead of the verified
`1.0000`. Parsing the captured bytes fixes it. Corruption still fails, and embedded
CRLF/quotes/Unicode survive. Both new tests pass locally and on Windows/Linux CI.
The repair changes no accepted appearance, schema or encoding. Its diff and
affected dependencies were reviewed; no further blocking findings remain.
