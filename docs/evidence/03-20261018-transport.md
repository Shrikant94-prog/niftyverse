The HTTPX mock tests establish lifecycle and selection of the HTTP/1 fallback,
not real remote HTTP/2 negotiation. Default HTTPX ALPN supports HTTP/1 fallback.
No live calls were made. No internal background task or eager job queue is created.
One owner prevents adapter-local limit multiplication within the process; callers
must use a single acquisition process per provider/account/IP context. HTTPX pools
are scoped to that owner and cookies remain in memory. Unapproved redirects fail
explicitly rather than silently following them.

A received network chunk may cross a byte ceiling; that chunk is counted but never
appended or returned. No successful body exceeds its ceiling. HTTP compression is
rejected (identity requested), avoiding an unbounded transparent decoder. The
limits bound returned buffers, not the interpreter/native transport's total RSS.

a review-discovered ownership gap. Raw iteration rejected already-buffered mock
responses; identity-only decoded iteration supports both streaming and buffered
HTTPX responses. A PowerShell-created UTF-8 BOM triggered Ruff's renderer panic;
rewriting the owned file as BOM-free UTF-8 restored it. No dependency upgrade.
